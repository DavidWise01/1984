Release integrity and limits

This audit points to chapter files in GitHub's versioned repository. Git commit history records successive additions and homepage/README updates; it is not a cryptographic claim that the work can never be altered. Past releases should remain unchanged unless an explicit correction is documented. The browser-based observation log in each chapter is session-only, not a centralized persistent memory system.

Artwork and prose are original interpretive work. Orwell’s novel remains copyrighted in the United States. No extended original passages are reproduced. The chronological source correction made at Episode 015 is retained in the canonical README ledger.
